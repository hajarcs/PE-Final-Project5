# Internal IT Help Desk – Prompt Library

A reusable prompt library developed as part of the Prompt Engineering and Responsible AI Use training program.

The library contains five structured prompts for internal IT support tasks, using the RACE framework, approved IT facts, and human review.

## Training Program

This project was completed as part of the Prompt Engineering and Responsible AI Use training program at SDAIA Academy, under the supervision of Abdullah Khalid Alshahrani. 

The project demonstrates the practical application of prompt engineering and responsible AI use — building a clean, approved prompt library through structured RACE prompts, reusable templates with variables and fixed output formats, safe handling of sensitive data, verification and responsible-use rules, and a documented three-test quality report.

## The Five Prompt Templates

| Template | Description |
|---|---|
| `IT-Resolve-Ticket` | Writes clear responses to employee IT support tickets. |
| `IT-Summarize-Ticket` | Summarizes ticket conversations into three lines for the next technician. |
| `IT-Route-Tickets` | Classifies tickets and identifies the reason and next step. |
| `IT-Explain-Answer` | Simplifies technical answers for non-technical employees. |
| `IT-Translate-Status` | Translates service messages between Arabic and English without changing facts. |

## How to Use

1. **Pick:** Select a template from the Library Index.
2. **Fill:** Enter the required variables using fictional or masked data.
3. **Run:** Copy the completed prompt into an AI tool.
4. **Review:** Verify the output using IT facts and the CHECK section before use.

## Prompt Structure

The templates follow the RACE framework:

| Component | Purpose |
|---|---|
| ROLE | Defines the AI's role |
| ACTION | Defines the task |
| CONTEXT | Provides background and facts |
| EXPECTATION | Defines the expected output |

Additional sections include INPUT, RULES, and CHECK.

## Responsible AI Use

- Protect sensitive employee information.
- Use only approved IT facts.
- Avoid invented information and unsupported promises.
- Test prompts with different inputs and edge cases.
- Keep human review before using AI-generated responses.
